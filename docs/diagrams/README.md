# Діаграми до пояснювальної записки

Згенеровано з коду проєкту. Кожна діаграма у двох форматах:
- **`.svg`** — векторний, вставляти у Word 2016+ (Вставка → Зображення). Масштабується без втрати якості.
- **`.png`** — растровий (scale ×2, біле тло), запасний варіант для старих редакторів / Google Docs.

**Якісні джерела — у `drawio/*.drawio`** (відкрити у diagrams.net — app.diagrams.net або desktop —
за потреби підправити, далі **File → Export as → SVG / PNG**; для PNG постав Zoom 200%, Border 10,
біле тло). Експортовані SVG/PNG замінюють mermaid-версії. Mermaid-джерела у `src/*.mmd` —
застарілі для діаграм, що мають drawio-джерело (2.1, 2.2, 2.3, 3.2, 3.3); правити лише drawio.

Нотація по діаграмах:

- **2.1 / 2.2 (BPMN 2.0):** доріжки (ролі), 👤 User Task / ⚙ Service Task, ромб = exclusive-шлюз,
  тонке коло = старт, товсте = кінець, суцільна стрілка = sequence flow, пунктир = цикл/асоціація.
- **2.3 (UML пакети):** пакет = «папка» (shape=folder з табом), компоненти у сітці,
  залежності = пунктирна `«use»`-стрілка з відкритим вістрям.
- **3.2 (UML компоненти):** компонент = `shape=module` (іконка з табами) зі стереотипом «component»;
  ○ lollipop = наданий інтерфейс (provided), пунктир `«use»` = потрібний (required),
  ◆ суцільна = композиція (дерево рендера), «store»/«artifact» = стан і сховище.
  Заголовок у діаграму не вшито — підпис дає Word.
- **3.3 (UML Activity):** ● початковий вузол, ◉ кінцевий, ромб = рішення/злиття,
  guard у `[дужках]`, заокруглений прямокутник = дія, жовті області = групи
  «Лінійний імпульс» / «Кутовий імпульс» (виконуються послідовно, як у коді `Target.jsx`).
